# aigjx

Zero-cost, fully-automated multilingual guide site for **free AI online tools** (en-US / es-MX / id-ID).

## Hard constraints (non-negotiable)
- **No generative AI in content creation.** All page text is assembled from Jinja2 templates + snippet/FAQ/long-tail CSV libraries via deterministic (seed-based) recombination. No LLM rewrites, summaries, or original copy.
- **Zero cash spend.** GitHub Actions + Cloudflare Pages (Git integration) only. Translation uses free, key-less public endpoints (Google free endpoint, Edge anonymous token, community DeepLX nodes). No paid API / server / translation service.
- **Self-healing.** Source health, translation failover, compliance/SEO checks, build precheck + rollback, and weekly backups are all built in — no daily human maintenance.

## Stack
GitHub + GitHub Actions + Hugo (static) + RSSHub/RSS collection + free multi-source translation + Jinja2 + Cloudflare Pages.

## Layout
```
config/      settings / locales / sources (all behavior is config-driven)
pipeline/    8 modules: collect, translate, keywords, generate, compliance, seo, selfheal, publish
templates/   Jinja2 page + component templates
site/        Hugo site (multilingual, flat permalinks, structured data)
data/        CSV libraries (snippets, faq, localization, blacklist, longtail) + runtime state
docs/        STRUCTURE.md, DEPLOY.md, RUNBOOK.md
.github/     daily-pipeline / monthly-keywords / weekly-health workflows
```

## Local smoke test (no publish)
