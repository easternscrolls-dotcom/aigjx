# Agentic Tools — AI Agent & Automation Directory

A clean, fast, ad-light static directory of AI agents, agent frameworks, and
automation tools. Built with [Hugo](https://gohugo.io/) and deployed on
Cloudflare Pages.

## Stack

- **Hugo** static site (single language: English).
- **Cloudflare Pages** Git integration: build command `cd site && hugo --minify`,
  output `site/public`, served at `https://freeai.72tool.com/`.
- **Zero external services / zero paid APIs.** Content is plain Markdown.

## Structure

```
autoguide-station/
├── build_search_index.py     # regenerates site/static/search.json from tool front matter
└── site/
    ├── hugo.toml             # site config (baseURL, taxonomies)
    ├── assets/               # (none — CSS/JS are served as static files)
    ├── content/
    │   ├── _index.md         # homepage
    │   ├── about.md
    │   └── tools/*.md        # one file per tool
    ├── layouts/              # baseof, partials, section, taxonomy templates
    └── static/
        ├── css/main.css
        ├── js/search.js      # zero-dependency client-side search
        ├── js/tools.js       # category filter on /tools/
        ├── robots.txt
        └── search.json       # committed; generated by build_search_index.py
```

## Local workflow

```bash
# 1. Edit/add tool entries under site/content/tools/*.md
# 2. Regenerate the search index (plain Python, no deps)
python build_search_index.py
# 3. Build & preview
cd site && hugo server
# 4. Commit and push — Cloudflare rebuilds automatically
```

## Tool entry format

```markdown
---
title: "Tool Name"
description: "One-line factual summary."
categories: ["Agent Frameworks", "Open Source"]
pricing: "Free / Open Source"
website: "https://example.com"
tags: ["framework", "open-source"]
date: 2026-08-13
---
Body copy (markdown). Keep it factual; link out to the official site.
```

## Notes

- Listings are editorial and for reference only. Always verify pricing and
  features on the tool's official website.
- Category slugs are derived via Hugo's `urlize`; the category filter and
  tool-card links stay in sync automatically.
