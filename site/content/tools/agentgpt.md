AgentGPT is a browser-based platform that lets you configure and deploy
autonomous AI agents directly in the browser to achieve goals you specify, with
optional self-hosting.

## Highlights

- Zero-install web UI — assemble and run agents instantly.
- Goal-oriented agent that chains thoughts and actions.
- Self-hostable for private deployment.

Accessible entry point for experimenting with autonomous agents.
