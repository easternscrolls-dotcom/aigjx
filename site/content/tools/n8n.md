n8n is an open-source, node-based workflow automation tool that connects
hundreds of apps and services with code-level flexibility, supporting
self-hosting and AI-native nodes.

## Highlights

- Visual node editor with branching, loops, and merges.
- 400+ integrations plus the ability to write custom JavaScript/Python.
- Self-hostable for data control; fair-code licensing.

A favorite for teams wanting Zapier-like automation without vendor lock-in.
