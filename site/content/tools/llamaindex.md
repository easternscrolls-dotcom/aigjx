LlamaIndex (formerly GPT Index) is an open-source data framework for building
LLM-powered applications over private or domain-specific data, with strong agent
and tooling support.

## Highlights

- Ingestion and indexing of many data sources for retrieval-augmented generation.
- Query engines, agents, and workflow primitives.
- Language SDKs (Python and TypeScript) with broad connector support.

A go-to choice when the core problem is "answer questions over my data."
