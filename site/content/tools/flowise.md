Flowise is an open-source, drag-and-drop UI for building LLM apps and agents as
visual flows, built on LangChain, with self-hosting and API deployment.

## Highlights

- Canvas-based builder for chains, agents, and retrieval.
- Export and serve flows via API.
- Self-hostable with chat and embeddings integrations.

Good for quickly standing up a prototype without writing glue code.
