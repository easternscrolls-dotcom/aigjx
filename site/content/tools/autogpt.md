AutoGPT is an open-source project that lets you set a high-level goal and have an
autonomous AI agent plan and execute tasks by chaining Large Language Model
calls, using tools to browse the web, write files, and run code.

## Highlights

- Goal-driven agent loop: define an objective, the agent breaks it into tasks.
- Connects to tools for web browsing, file operations, and code execution.
- Self-hosted and extensible; a large community ecosystem.

Verify current capabilities and setup on the official site before adopting it
for production workflows.
