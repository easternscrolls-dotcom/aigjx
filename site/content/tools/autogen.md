AutoGen is Microsoft's open-source framework for building multi-agent
conversation systems where multiple LLM-backed agents (and humans) collaborate
to solve tasks via configurable, event-driven workflows.

## Highlights

- Conversational agent pattern with customizable agent roles.
- Native support for human-in-the-loop participation.
- Code execution and tool-use capabilities built in.

Backed by Microsoft research; good for prototyping agent collaborations.
