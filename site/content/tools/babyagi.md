BabyAGI is a minimal open-source script that demonstrates an autonomous
task-driven agent: it creates, prioritizes, and executes tasks using an LLM to
reach a defined objective.

## Highlights

- Tiny, readable codebase — a great learning reference.
- Task-creation and prioritization loop driven by an LLM.
- Sparked a wave of autonomous-agent experiments.

More of an educational prototype than a production platform.
