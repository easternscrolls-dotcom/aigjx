LangChain is a widely-used open-source framework for building applications
powered by large language models, providing composable chains, memory,
tool-calling, and agent abstractions.

## Highlights

- Large library of integrations with models, vector stores, and tools.
- Abstractions for prompts, memory, retrieval (RAG), and agents.
- Companion products (LangSmith, LangGraph) for observability and workflows.

Best suited for developers building custom LLM applications rather than
non-technical users.
