Dify is an open-source LLM app development platform that provides a visual
builder for agents, RAG pipelines, and workflows, with both self-hosted and
cloud options.

## Highlights

- Visual orchestration of prompts, knowledge bases, and tools.
- Built-in RAG with document ingestion and embedding management.
- API and SDK exposure for production deployment.

A pragmatic bridge between no-code building and developer extensibility.
