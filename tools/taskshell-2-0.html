TaskShell 2.0 使用教程

### 1. 创建任务

  1. 登录TaskShell 2.0平台。
  2. 点击“创建任务”按钮。
  3. 输入任务名称和描述。
  4. 设置任务优先级和截止日期。
  5. 分配任务给团队成员。

### 2. 分配任务

  1. 在任务列表中找到需要分配的任务。
  2. 点击任务右侧的“分配”按钮。
  3. 选择团队成员并设置权限。
  4. 点击“确认”完成分配。

### 3. 跟踪任务

  1. 在任务列表中查看任务进度。
  2. 点击任务名称进入任务详情页。
  3. 查看任务日志和团队成员的更新。
  4. 对任务进行评论和反馈。

### 4. 完成任务

  1. 当任务完成时，点击任务右侧的“完成”按钮。
  2. 任务状态将更新为已完成。
  3. 可对任务进行评价和总结。
