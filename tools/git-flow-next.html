使用教程

使用 git-flow-next 的基本步骤

  1. 安装 git-flow-next

在终端中运行以下命令安装 git-flow-next:

```bash

npm install -g git-flow-next

```

  1. 初始化工作流

在你的 Git 仓库根目录下，运行以下命令初始化工作流:

```bash

git flow init

```

  1. 创建新功能

使用以下命令创建一个新功能分支:

```bash

git flow feature start <feature-name>

```

  1. 开发功能

在新创建的分支上开发你的功能。

  1. 完成功能并合并

完成功能后，使用以下命令将功能分支合并到 develop 分支，并创建一个 release 分支:

```bash

git flow feature finish <feature-name>

```

  1. 发布版本

将 release 分支合并到 master 分支，并创建一个 hotfix 分支进行修复:

```bash

git flow release publish <release-name>

git flow release finish <release-name>

```
