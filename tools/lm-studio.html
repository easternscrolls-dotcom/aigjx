使用教程

LM Studio 使用教程

### 小节一：软件安装与启动

  1. 下载 LM Studio 安装包，选择合适的版本进行安装。
  2. 完成安装后，双击桌面图标或开始菜单中的 LM Studio 快捷方式启动软件。
  3. 首次启动时，软件会提示注册或登录，请根据提示操作。

### 小节二：模型加载与配置

  1. 打开软件后，点击左侧菜单栏的“模型管理”选项。
  2. 在模型管理界面，点击“添加模型”按钮，选择需要加载的 GGUF 模型文件。
  3. 模型加载完成后，在列表中可以看到加载的模型信息，点击模型名称可查看详细信息。
  4. 根据需要调整模型参数，如输入尺寸、输出尺寸等。

### 小节三：模型运行与监控

  1. 在模型管理界面，选中需要运行的模型，点击“运行”按钮。
  2. 模型开始运行后，软件会显示运行进度和结果。
  3. 若需要暂停或停止模型运行，可点击相应的按钮操作。
  4. 运行完成后，软件会自动保存结果，并提供下载选项。

### 小节四：离线推理与导出

  1. 在模型管理界面，选中需要导出的模型，点击“导出”按钮。
  2. 选择导出路径，设置导出参数，如输出尺寸、格式等。
  3. 导出完成后，模型将离线运行，无需网络连接。
  4. 如需在离线环境下使用模型，请确保已将模型导出到相应设备。
