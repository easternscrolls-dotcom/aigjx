使用 Skills 工具

### 1. 克隆仓库

  1. 打开终端或命令行。
  2. 输入 `git clone [仓库地址]` 并回车。
  3. 克隆完成后，进入仓库目录。

### 2. 安装依赖

  1. 输入 `pip install -r requirements.txt` 并回车。
  2. 等待依赖安装完成。

### 3. 运行示例

  1. 输入 `python example.py` 并回车。
  2. 查看示例代码运行结果。

### 4. 开发自定义技能

  1. 在 `skills` 目录下创建新的 Python 文件。
  2. 编写技能逻辑。
  3. 在 `example.py` 中导入并使用新技能。
