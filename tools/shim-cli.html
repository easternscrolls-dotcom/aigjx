Shim-cli 使用教程

### 1. 安装 Shim-cli

首先，您需要在您的计算机上安装 Node.js 和 npm。然后，通过以下命令安装 Shim-cli:

```bash

npm install -g shim-cli

```

### 2. 配置 Shim-cli

安装完成后，您需要配置 Shim-cli，以连接到您的代理服务器。运行以下命令来配置您的代理设置：

```bash

shim-cli config

```

按照提示输入您的代理服务器地址和端口。

### 3. 监控网页内容

配置完成后，您可以使用以下命令来监控指定网页的内容：

```bash

shim-cli monitor <url>

```

这将启动一个监控任务，并显示代理发送的内容。

### 4. 隐藏敏感信息

如果您想隐藏某些敏感信息，可以使用以下命令来设置正则表达式匹配规则：

```bash

shim-cli rule add <regex> <replacement>

```

这将添加一个规则，用于在监控内容中替换匹配的敏感信息。

注意：请确保您的正则表达式正确无误。
