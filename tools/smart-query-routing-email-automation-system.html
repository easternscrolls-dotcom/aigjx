  1. 访问 Smart-Query-Routing-Email-Automation-System 官网，注册账号并登录。
  2. 阅读并同意服务条款。

### 2. 配置邮箱

  1. 在设置页面，添加您的邮箱账户。
  2. 输入邮箱地址和密码，点击验证。
  3. 等待系统验证邮箱并完成配置。

### 3. 设置路由规则

  1. 在路由规则页面，创建新的规则。

### 4. 检查与测试

  1. 发送测试邮件到您的邮箱，检查自动化流程是否正常。
  2. 根据测试结果调整设置，确保邮件处理无误。
