使用教程

小节标题：Gumloop 基础操作

  1. 注册与登录
  2. 访问 Gumloop 官网，点击“注册”或“登录”按钮。
  3. 使用邮箱或社交媒体账号进行注册或登录。
  1. 创建工作流
  2. 登录后，点击页面右上角的“创建工作流”按钮。
  3. 输入工作流名称，选择合适的模板或从空白开始。
  4. 点击“下一步”，进入工作流编辑界面。
  1. 添加 LLM 节点
  2. 在工作流编辑界面，点击左侧的“LLM”节点库。
  3. 选择需要的 LLM 节点，拖拽到工作流画布上。
  4. 配置节点参数，如输入数据、输出格式等。
  1. 连接节点
  2. 将一个节点的输出端与另一个节点的输入端相连，创建数据流。
  3. 可以通过拖拽线段来连接节点，形成工作流。

小节标题：工作流管理与优化

  1. 预览与测试
  2. 点击工作流画布上的“预览”按钮，查看工作流运行结果。
  3. 根据需要调整节点配置，优化工作流。
  1. 保存与分享
  2. 完成工作流配置后，点击右上角的“保存”按钮。
  3. 可以将工作流分享给团队成员或导出为模板。
  1. 调整与优化
  2. 定期检查工作流运行情况，确保数据准确性和效率。
  3. 根据业务需求，调整节点配置或添加新节点。
