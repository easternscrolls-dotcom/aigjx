Skyvern 使用教程

### 小节一：安装与启动

  1. 下载 Skyvern 安装包，根据操作系统选择合适的版本。
  2. 解压安装包，运行安装程序。
  3. 按照提示完成安装，启动 Skyvern。

### 小节二：配置环境

  1. 打开 Skyvern，进入设置界面。
  2. 配置浏览器驱动，选择合适的浏览器和驱动路径。
  3. 设置 LLM 驱动，选择支持的 LLM 模型，配置 API 密钥。
  4. 保存设置，退出设置界面。

### 小节三：创建自动化任务

  1. 在 Skyvern 中，点击“新建任务”按钮。
  2. 选择任务类型，如网页浏览、表单填写等。
  3. 输入目标网址，设置任务参数。
  4. 设计任务流程，包括页面跳转、元素点击等操作。
  5. 保存任务，开始运行。

### 小节四：调试与优化

  1. 运行任务，观察自动化过程。
  2. 如有错误，查看日志信息，定位问题。
  3. 调整任务参数或流程，优化自动化效果。
  4. 重复调试，直至任务运行正常。
