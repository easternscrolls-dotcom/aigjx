使用教程

MultiOn 使用教程

### 小节标题：账户注册与登录

  1. 访问 MultiOn 官网，点击“注册”按钮。
  2. 填写注册信息，包括邮箱、密码等，完成注册。
  3. 收到注册邮件后，点击邮件中的链接激活账户。
  4. 返回 MultiOn 官网，使用邮箱和密码登录账户。

### 小节标题：创建任务

  1. 登录 MultiOn 后，点击左侧菜单的“创建任务”。
  2. 选择任务类型，如“自动下单”、“填写表格”等。
  3. 根据任务需求，填写相关参数，如网站地址、关键词、填写内容等。
  4. 点击“保存”按钮，创建任务。

### 小节标题：任务设置与调度

  1. 进入任务列表，找到已创建的任务。
  2. 点击任务右侧的“设置”按钮，对任务进行详细设置。
  3. 设置任务执行时间、频率等参数。
  4. 点击“保存”按钮，完成任务设置。

### 小节标题：任务监控与执行

  1. 在任务列表中，查看任务执行状态。
  2. 如有需要，可对任务进行暂停、恢复或删除操作。
  3. 观察任务执行结果，确保任务按预期完成。
