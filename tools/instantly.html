使用教程

Instantly.ai 使用教程

### 小节一：账户注册与登录

  1. 访问 Instantly.ai 官网，点击“注册”按钮。
  2. 填写注册信息，包括邮箱、密码等，并同意服务条款。
  3. 点击“注册”完成账户创建。
  4. 使用注册邮箱接收验证邮件，点击链接完成邮箱验证。
  5. 返回 Instantly.ai 官网，使用邮箱和密码登录账户。

### 小节二：创建邮件模板

  1. 登录后，进入“邮件模板”页面。
  2. 点击“新建模板”按钮，选择模板类型（如：外贸开发信）。
  3. 在编辑器中，根据需求添加文本、图片、链接等元素。
  4. 保存模板，并设置模板名称以便后续使用。

### 小节三：批量发送邮件

  1. 进入“邮件发送”页面。
  2. 选择目标邮箱列表，可导入 CSV 文件或手动输入邮箱地址。
  3. 选择已创建的邮件模板，并设置发送时间（如：立即发送或定时发送）。
  4. 设置邮件发送频率（如：每天发送一次或每周发送一次）。
  5. 点击“发送”按钮，开始批量发送邮件。

### 小节四：域名预热与送达率管理

  1. 进入“域名管理”页面。
  2. 添加新的域名，并设置域名类型（如：A记录、CNAME等）。
  3. 对域名进行预热，提高邮件送达率。
  4. 查看邮件送达率数据，分析邮件发送效果。
  5. 根据数据调整邮件发送策略，提高邮件送达率。
