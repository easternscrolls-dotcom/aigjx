使用教程

小节标题：CrewAI 快速上手

### 1. 安装与配置

  1. 下载 CrewAI 的源代码，解压到本地目录。
  2. 打开终端，进入 CrewAI 目录。
  3. 运行 `pip install -r requirements.txt` 命令，安装依赖库。
  4. 配置环境变量，确保 CrewAI 可以在终端中直接运行。

### 2. 创建智能体角色

  1. 在 CrewAI 目录下，创建一个新的文件夹，命名为 `agents`。
  2. 在 `agents` 文件夹中，创建一个 Python 文件，命名为 `agent.py`。
  3. 在 `agent.py` 文件中，编写智能体的代码，实现角色的功能。
  4. 在 `agent.py` 文件的最后，添加 `from crewai.agent import Agent` 语句，并创建一个 `Agent` 类的实例。

### 3. 配置任务分配

  1. 在 CrewAI 目录下，创建一个新的文件夹，命名为 `tasks`。
  2. 在 `tasks` 文件夹中，创建一个 Python 文件，命名为 `task.py`。
  3. 在 `task.py` 文件中，编写任务的代码，定义任务的具体内容和执行逻辑。
  4. 在 `task.py` 文件的最后，添加 `from crewai.task import Task` 语句，并创建一个 `Task` 类的实例。

### 4. 运行 CrewAI

  1. 在终端中，进入 CrewAI 目录。
  2. 运行 `python run.py` 命令，启动 CrewAI。
  3. 观察终端输
