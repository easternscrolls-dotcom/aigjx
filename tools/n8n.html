n8n 使用教程

### 小节标题：准备工作

  1. 访问 n8n 官网（[https://www.n8n.io/](https://www.n8n.io/)），下载并安装 n8n。
  2. 打开 n8n，创建一个新的工作空间。
  3. 配置工作空间的连接，包括 API 密钥、数据库等。

### 小节标题：创建工作流

  1. 在工作空间中，点击“创建工作流”按钮。
  2. 从左侧节点库中选择所需的节点，如 HTTP 节点、数据库节点等。
  3. 将选中的节点拖拽到工作流画布上。
  4. 双击节点，配置其参数，如 URL、请求方法等。

### 小节标题：连接节点

  1. 将节点按照工作流逻辑连接起来，使用鼠标左键点击一个节点的输出端口，然后拖拽到下一个节点的输入端口。
  2. 可以使用条件节点来实现分支逻辑，根据条件判断执行不同的节点。
  3. 保存工作流。

### 小节标题：运行与监控

  1. 点击工作流画布右上角的“运行”按钮，启动工作流。
  2. 观察工作流运行状态，包括节点执行成功、失败等信息。
  3. 如果需要，可以暂停或停止工作流。
  4. 定期检查工作流运行情况，确保工作流按预期执行。
