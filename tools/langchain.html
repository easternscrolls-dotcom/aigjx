使用教程

LangChain 使用教程

### 小节一：安装与配置

  1. 下载 LangChain 的最新版本。
  2. 解压下载的文件到本地目录。
  3. 在终端中进入 LangChain 目录。
  4. 运行 `pip install -r requirements.txt` 安装依赖。

### 小节二：创建项目

  1. 在 LangChain 目录下创建一个新的文件夹，命名为 `my_project`。
  2. 在 `my_project` 文件夹中创建一个名为 `main.py` 的 Python 文件。
  3. 在 `main.py` 中导入 LangChain 的相关模块。

### 小节三：编写代码

  1. 在 `main.py` 中定义一个 LangChain 实例。
  2. 使用 `langchain` 提供的链式调用功能，添加所需的工具和插件。
  3. 使用 `langchain` 的记忆管理功能，实现数据的持久化存储。

### 小节四：运行项目

  1. 在终端中进入 `my_project` 文件夹。
  2. 运行 `python main.py` 启动项目。
  3. 使用浏览器或其他工具访问项目地址，查看效果。
