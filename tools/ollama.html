Ollama 使用教程

### 小节标题：安装与配置

  1. 下载 Ollama：访问 [Ollama 官网](https://ollama.io/)，根据你的操作系统下载相应的安装包。
  2. 安装依赖：打开终端或命令提示符，执行 `pip install -r requirements.txt` 命令，安装所有依赖。
  3. 配置环境变量：将 Ollama 的路径添加到系统环境变量中，以便在任何位置运行 Ollama。

### 小节标题：运行模型

  1. 下载模型：在 Ollama 官网上下载你想要运行的模型，例如 Llama 或 Qwen。
  2. 解压模型：将下载的模型文件解压到本地目录。
  3. 运行模型：在终端或命令提示符中，进入模型所在的目录，执行 `ollama run model_name` 命令，其中 `model_name` 是模型文件名。

### 小节标题：使用参数

  1. 设置模型参数：在运行模型时，你可以通过 `-p` 参数设置模型参数，例如 `-p max_length=100` 设置最大长度为 100。
  2. 设置输出格式：使用 `-o` 参数设置输出格式，例如 `-o json` 输出 JSON 格式。
  3. 设置设备：使用 `-d` 参数设置运行模型的设备，例如 `-d cpu` 使用 CPU 运行模型。

### 小节标题：常见问题

  1. 问题：无法找到模型。

解决：请确保模型文件已正确下载并放置在正确的目录。

  1. 问题：运行模型时出现错误。

解决：检查模型是否支持你的操作系统和 Python 版本，并确保所有依赖都已正
