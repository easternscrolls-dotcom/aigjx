使用教程

使用Agent Toolkit for AWS教程

### 1. 注册AWS账户

  1. 访问AWS官网并注册一个账户。
  2. 完成账户激活和验证流程。

### 2. 安装Agent Toolkit

  1. 访问Agent Toolkit的GitHub页面。
  2. 下载并解压安装包。
  3. 运行安装脚本，按照提示完成安装。

### 3. 创建MCP服务器

  1. 打开Agent Toolkit控制台。
  2. 点击创建MCP服务器。
  3. 选择合适的配置，填写服务器名称和描述。
  4. 点击创建，等待服务器启动。

### 4. 部署技能和插件

  1. 在控制台中找到MCP服务器。
  2. 点击添加技能或插件。
  3. 选择技能或插件，上传配置文件。
  4. 点击部署，等待部署完成。

### 5. 测试和监控

  1. 在控制台中查看技能和插件的状态。
  2. 使用测试工具进行测试。
  3. 监控服务器性能，确保正常运行。
